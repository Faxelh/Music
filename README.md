# Music 🎶

Petit outil pour **organiser les fichiers musicaux** d'un dossier : retirer, réordonner ou renuméroter les préfixes numériques (`001`, `002`… `00n`) devant les noms de fichiers.

## ✨ Fonctionnalités

- Retirer les numéros au début des noms de fichiers
- Renuméroter les fichiers à la suite (`001 - titre.mp3`, `002 - titre.mp3`…)
- Garantir un numéro **unique** par fichier
- Réordonner les morceaux selon l'ordre voulu

## 🚀 Utilisation

```bash
git clone https://github.com/Faxelh/Music.git
cd Music
python main.py
```

Indiquez ensuite le dossier contenant vos fichiers musicaux et choisissez l'action à effectuer.

> ⚠️ Faites une copie de sauvegarde de votre dossier avant de renommer vos fichiers.
